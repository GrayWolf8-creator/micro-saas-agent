# GW8 Base Signal Agent API

> Monetized AI Trading Signal Endpoint on Base Mainnet.

## Service Specs
- Network: Base Mainnet (Chain ID 8453)
- Token Contract: 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913 (USDC)
- Pay To Wallet: 0xB4527dccaC81eB73d4988A51a4cb1FBBF2C3CaBd
- Protocol: x402 Micro-payments

## Endpoints

### [POST /api/agent](https://micro-saas-agent.onrender.com/api/agent)
- Price: 0.05 USDC
- Required Header: X-Payment-Tx (Base Mainnet Transaction Hash)
- Description: Returns live ETH/USD market analytics, 24h momentum change, algorithmic signal (BUY/HOLD/SELL), and confidence scores upon valid payment verification.
